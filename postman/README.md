# Postman коллекция

## Описание

Эта директория содержит Postman коллекции для тестирования API.

## Файлы

- **REST_API_Template.postman_collection.json** - Основная коллекция с запросами и тестами
- **generated-collection.json** - Автоматически сгенерированная коллекция из Swagger (создается скриптом)

## Использование

### Импорт коллекции

1. Откройте Postman
2. Нажмите "Import"
3. Выберите файл `REST_API_Template.postman_collection.json`
4. Коллекция будет импортирована со всеми запросами и переменными

### Настройка переменных

После импорта коллекции настройте переменные:

1. Откройте коллекцию
2. Перейдите на вкладку "Variables"
3. Убедитесь, что `baseUrl` установлен на `http://localhost:3000` (или ваш URL)

### Использование

1. **Запустите приложение**: `npm run start:dev`
2. **Выполните Register или Login** - токены автоматически сохранятся
3. **Используйте защищенные endpoints** - токен будет автоматически добавлен в заголовки

## Автоматическая генерация из Swagger

Для автоматической генерации коллекции из Swagger:

```bash
# Генерация для локального сервера
npm run postman:generate:local

# Или с указанием URL
SWAGGER_URL=http://localhost:3000/docs-json npm run postman:generate
```

Сгенерированная коллекция будет сохранена в `postman/generated-collection.json`.

## Тесты

Все запросы содержат автоматические тесты, которые проверяют:
- Статус код ответа
- Структуру ответа
- Время ответа
- Автоматическое сохранение токенов (для Register/Login)

## Переменные коллекции

- `baseUrl` - Базовый URL API (по умолчанию: http://localhost:3000)
- `accessToken` - Access токен (автоматически заполняется)
- `refreshToken` - Refresh токен (автоматически заполняется)
- `userId` - ID пользователя (автоматически заполняется)

## Структура

```
Auth/
├── Register          # Регистрация (сохраняет токены)
├── Login            # Вход (сохраняет токены)
├── Get Current User # Получение информации о пользователе
├── Refresh Token    # Обновление токена
├── Logout           # Выход
├── Forgot Password  # Запрос сброса пароля
└── Reset Password  # Сброс пароля
```
