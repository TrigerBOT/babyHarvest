# Полные данные о беременности по дням (1-280)

Этот файл содержит структурированные данные о развитии плода и изменениях в организме матери для всех 280 дней беременности.
Данные основаны на информации Всемирной организации здравоохранения и медицинских источниках.

**Формат**: Каждый день представлен в формате:
```
#### День X
- **day**: X
- **week**: Y
- **trimester**: Z
- **babySize**: размер (сравнение)
- **babyWeight**: вес
- **babyDevelopment**: описание развития
- **motherChanges**: изменения у матери
- **tips**: 
  - совет 1
  - совет 2
  - совет 3
```

## Шаблоны для генерации данных

### Недели 19-27 (Триместр 2, дни 127-189)

**Общие характеристики:**
- Размер плода: от 83 мм до 240 мм (от большого банана до кукурузы)
- Вес плода: от 0.6 г до 900 г
- Основные изменения: активное развитие всех систем, формирование жировой ткани, развитие органов чувств

### Недели 28-40 (Триместр 3, дни 190-280)

**Общие характеристики:**
- Размер плода: от 250 мм до 520 мм (от баклажана до арбуза)
- Вес плода: от 1000 г до 3500 г
- Основные изменения: окончательное созревание органов, накопление жира, подготовка к родам
