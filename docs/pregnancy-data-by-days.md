# Данные о беременности по дням (1-280)

Этот файл содержит структурированные данные о развитии плода и изменениях в организме матери для каждого дня беременности.
Данные основаны на информации Всемирной организации здравоохранения и медицинских источниках.

Формат данных соответствует структуре таблицы `pregnancy_days`:
- day: номер дня (1-280)
- week: номер недели (1-40)
- trimester: триместр (1-3)
- babySize: размер плода с сравнением
- babyWeight: вес плода
- babyDevelopment: описание развития
- motherChanges: изменения в организме матери
- tips: советы на день (массив строк)

Данные в этом файле структурированы для удобного парсинга и импорта в таблицу `pregnancy_days`.

Каждая запись содержит:
- **day**: номер дня беременности (1-280)
- **week**: номер недели (1-40)
- **trimester**: номер триместра (1-3)
- **babySize**: размер плода с сравнением с предметом
- **babyWeight**: вес плода
- **babyDevelopment**: описание развития плода
- **motherChanges**: изменения в организме матери
- **tips**: массив советов (можно преобразовать в JSON массив)
